# Notes App Android — Ngô Hồng Bảo

**Đề tài:** Thiết kế và xây dựng ứng dụng quản lý ghi chú cá nhân trên Android  
**Sinh viên:** Ngô Hồng Bảo  
**MSSV:** 2311553403  
**Lớp học phần:** 23DTH1D  
**Trường:** Đại học Nguyễn Tất Thành — Khoa Công nghệ Thông tin

## Công nghệ
- Java + XML
- SQLite / SQLiteOpenHelper
- Activity, Intent, ListView + Custom Adapter
- SharedPreferences
- AlarmManager + BroadcastReceiver

## Chức năng chính
- CRUD ghi chú
- Tìm kiếm tiêu đề / nội dung
- Đánh dấu quan trọng, ghim, danh mục, ưu tiên
- Lọc và nhiều kiểu sắp xếp
- Reminder + Notification
- Thùng rác, khôi phục và xóa vĩnh viễn
- Thống kê, Dark Mode
- Sao lưu / khôi phục JSON
- Chia sẻ ghi chú
- Hoạt động offline với SQLite
